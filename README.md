# 渡言 · 自绘小样

全部字形由程序从零构造，不使用任何现成字体的轮廓。

- `pen.py`：「一支笔」。沿中心线扫出笔画轮廓，笔画越接近竖直越粗（竖粗横细）。
- `latin.py`：英文字母。比例参考 Anthropic Serif（x 高度 540、大写 720），轮廓自己构造；主干 100、细线 50，衬线短而利落。
- `han.py`：汉字和假名。宋体笔法零件：横（末端带喙）、竖（顿笔、垂露 / 悬针）、撇、捺（平出捺脚）、点（水滴）、提、折、钩；竖画 104、横画 60。
- `build_sample.py`：装配成 `sample/Duyan-Sample.ttf`。
- `sample/index.html`：小样展示页（`python3 -m http.server 8766` 后打开 http://localhost:8766/sample/）。

`sample/ref-anthropic-serif.png` 是参考字体的本地渲染图，只用来对照，不要公开发布。

## 笔法的对应关系

| 西文 | 汉字 |
| --- | --- |
| 楔形衬线 | 横画末端的喙 |
| 球形收笔（a、c、r） | 点 |
| 主干 100 / 细线 50 | 竖画 104 / 横画 60 |

## 轮廓质量的规矩

- 笔画相接时，一笔的端头要整个藏进另一笔里，不能刚好碰边（横撇用 `hengpie`，肩的下沿正好贴着撇的起笔切口）。
- 不相接的笔画之间至少留 36 单位的空，不能留一条细缝。
- 斜笔上的衬线用 `dserif`，托角顺着斜边收进笔画里。
- 球形收笔用 `ball_end`，球的外缘和笔画外缘相切。
- `sweep` 采样出来的密集点会先拟合成少量平滑曲线再写进字体（`pen.smooth_open` / `smooth_closed`），否则坐标取整会让大字号下的边缘发毛。

检查：`python3 tools/defects.py sample/Duyan-Sample.ttf [字符] --crops 输出目录`，报告毛刺、缺口和窄缝的位置。笔尖、喙尖、笔画交叉的夹角也会被标出来，需要放大看一眼再判断。
