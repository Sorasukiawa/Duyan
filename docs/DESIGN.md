# 设计与造字方式

全部字形由程序从零构造，不使用任何现成字体的轮廓。

## 造字方式：轮廓优先

每一笔（连笔也算一笔）直接画成一条闭合轮廓，和在造字软件里画字一样：在曲线的极值点和转角处放节点，写明经过这个点时的走向；两个节点之间的弯度用「张力」控制（控制柄长度 = 张力 × 节点到两条切线交点的距离，0.55 左右是圆弧，越大越方）。

- `outline.py`：节点、轮廓、张力曲线；`Shape.mapped()` 做精确的轴向缩放（汉字出字体前纵向压扁用）。
- `latin.py`：英文小写和公用零件（竖连衬线、拱、碗、斜笔衬线）。每个字母一条外轮廓（加字怀），竖和拱、竖和碗相接的地方直接放一个角点。x 高度 540、大写 720，主干 100、细线 50，衬线短而利落。
- `caps.py`：英文大写（大写主干 108、细线 52）。
- `figures.py`：数字（齐线，高 700）和西文标点。
- `kern.py`：常用字距对，按形状分组写。
- `han.py`：汉字和假名。宋体笔法：横（末端带喙）、竖（斜切起笔、垂露 / 悬针）、撇、捺（平出捺脚）、点、提；横折、横撇、横钩、横折钩、「了」的横撇连弯钩、「辶」的横折折撇、斜钩（我、成、民）、竖提（以、长、比）、横折弯钩（几、九）、横斜钩（气）、竖弯（四、西）都画成一条轮廓，转角的肩直接画在里面。竖画 104、横画 60；`weight()` 按轮廓条数整体减细（档位见 [造字规范](RULES.md)「粗细」）。
- `parts.py`：汉字部件（亻 氵 讠 辶 艹 宀 心 女 木 月 忄 阝 纟……）。部件在整字坐标里画（设计框 `FULL = (70, −70, 930, 880)`），`into(格子)` 把它放进左右、上下的某一格：位置按格子缩放，横竖的粗细不变，点、钩、撇、捺的大小按 `m.k` 缩得少一点。
- `chars.py`：用部件拼出来的常用字（第一批 86 个），`lr()`、`tb()`、`bao()` 是左右、上下、半包围结构的拼法。
- `chars2.py`：第二批常用字（47 个高频字）和只在这批用到的部件（夕、厶、八、彳、云、𤴓……）。
- `chars3.py`：第三批常用字（98 个高频字）和这批的部件（首、羊、青、广、牛、壬、寺，扁的心字底……）。
- `chars4.py`：第四批常用字（100 个高频字）和这批的部件（右耳刀、攵、斤、艮、贝、隹、冫、礻、巴、弓……）。部件压进窄框时笔画会挤、捺脚会往右冲，这几个部件带了收短捺的写法（如 `you_r`、`pu(na_end=…)`）。
- `layout.py`：结构规范（字面框、部件间距、重心范围）和按间距自动摆部件的工具，说明见 [STRUCTURE.md](STRUCTURE.md)。
- `glyphs.py`：把字收集起来摆好位置。汉字在设计坐标里画，这里整字纵向压到 0.93、放到字身正中（见 [STRUCTURE.md](STRUCTURE.md)「字面」）。
- `build.py`：先检查，再装配成 `sample/Duyan-Sample.otf`（CFF，直接存三次曲线）。`--strict` 时有问题就不出字体。
- `tools/brand.py`：用字体自己的轮廓生成文字标、单字图标和封面（`brand/`）。
- `tools/similarity.py`：原创性核对，把渡言逐字和本机的现成字体比相似度（见下面「检查」）。
- `sample/index.html`：小样展示页（`python3 -m http.server 8766` 后打开 http://localhost:8766/sample/）。

## 检查

`tools/check.py` 按设计意图核对，不猜「这个尖是不是故意的」：

- 露头：标了 `hid`（应该藏进别的笔画）的点没被盖住，或离边不到 3 单位。
- 打结：轮廓自己和自己相交。
- 尖角：露在外面、内角小于 40° 却没标 `tip` 的角。
- 擦边 / 贴边：两笔的边以小于 15° 相交，或相距不到 4 单位并行。
- 窄缝：不相连的两块墨最近处不到 34 单位。
- 走向不顺：一段曲线两端标的走向对不上，会扭成 S 形或打卷（正常的 S 形拐点除外）。
- 小折角：轮廓上的点进出方向差 3°～25°，像没画顺的小拐。
- 被吞：一笔的节点全落在另一条轮廓里面。macOS 的系统渲染（CoreText，Mac 上的浏览器也用它）会按嵌套关系「纠正」轮廓方向，把这样的轮廓当成字怀，重叠处就画成了镂空；FreeType 和我们自己的预览图都看不出来。「月」框里的短横就因此并进了外框，横之间的空当做成挖空的字怀。

`tools/structure.py` 量每个汉字的字面（按轮廓量）、重心、灰度、部件间距和减细档位，按 [结构规范](STRUCTURE.md) 和 [造字规范](RULES.md) 报出超标的字；加一个图片路径会出总览图。只要几秒，画字途中常跑。

`tools/render_check.py` 在 macOS 上把系统渲染读出来的每条轮廓方向和字体文件里的逐条比对（会用 swiftc 编一个小工具到 `tools/.build/`），出字体后跑一遍。

`tools/proof.py 输出.png [字符]` 出带节点和控制柄的预览图，检查出的问题用红圈标出。检查通过以后，还要用系统渲染放大到几百像素看一遍。

`tools/similarity.py` 是原创性核对：把渡言逐字和本机的宋体、明朝体、楷体、仿宋、黑体和十几款西文衬线比墨的重合、轮廓线和骨架（笔画中线）的吻合度，拿参考字体彼此之间的数当基准线。参考字体只在内存里渲染算数字，不出图。比一次要几分钟，不放进 `build.py`，每加一批字手动跑一遍，规则见 [造字规范](RULES.md)。

## 笔法的对应关系

| 西文 | 汉字 |
| --- | --- |
| 楔形衬线 | 横画末端的喙 |
| 球形收笔（a、c、r） | 点 |
| 主干 100 / 细线 50 | 竖画 104 / 横画 60 |

## 已定的风格

- 汉字保持现在的粗细（竖画 104、横画 60），点用圆头水滴（对应西文的球形收笔），横画末端用圆润的喙。2026-10-20 比较过三档更细、更接近书宋的写法（竖 98 / 横 44 配侧点和三角喙，竖 80 / 横 32），最后定下保留原版。
- 要让字更规整，从结构入手（部件间距、字面、简单字撑开），不改粗细和收笔。
