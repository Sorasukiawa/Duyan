# 造字规范

画新字、改旧字都按这份来。它把散在代码、提交说明和 [设计与造字方式](DESIGN.md)、[汉字结构规范](STRUCTURE.md) 里的规矩收成一处；结构的具体数字以 STRUCTURE.md 和 [`layout.py`](../layout.py) 为准，这里不重复。单位是 1/1000 em。

规矩要改，先在这里改、写明日期和理由，再改代码；个别字要破例，在字的函数注释里写理由（结构上的例外记进 `layout.CENTER_EXCEPT`）。

## 一、原创

- 所有轮廓从零构造：汉字用 `han.py` 的笔画函数和各个部件拼，西文用 `latin.py` 的零件画。不导入、不描摹、不自动描边任何现成字体的轮廓或渲染图，也不照着它摆节点。
- 现成字体只能当量尺：量外框宽高、重心这类整字的数字做对照（STRUCTURE.md 里的字面饱满、重心范围就是这样来的），不量它的笔画位置和形状。
- 参考字体的渲染图只在本机看，不进仓库（见 `.gitignore`）。
- 每加一批字，跑一遍 `python3 tools/similarity.py`，它把渡言逐字和本机的宋体、明朝体、楷体、仿宋、黑体和十几款西文衬线比：
  - 整体：渡言和最像的那款字体之间的吻合度，要低于参考字体彼此之间的中位数，不然程序报错。
  - 单字：报出来的字放大看笔形。横画多的简单字（产、十、干）按外框拉齐后横线位置天然重合，数偏高多半是巧合。
  - 2026-10-21 的基准（351 个汉字）：渡言汉字的骨架最近邻 0.48，各家宋体、明朝体之间约 0.8，楷体和仿宋之间约 0.45～0.55；西文 0.71，西文衬线之间 0.71～0.96。

## 二、字身和坐标

- 汉字步进 1000，字身 y −120～880，基线在 0。所有墨（含捺脚、撇尖、提的圆头）落在字面框 (30, −100)–(975, 880) 里。
- 部件在设计框 `FULL = (70, −70, 930, 880)` 里按它最常见的样子画一次，放进别的字时用 `into(格子)` 映射：位置和长短跟着缩放，粗细不变。部件里再套部件用 `m.into(...)`，不另起一个 `into()`。
- 方向用角度：0 向右、90 向上、180 向左、270 向下。

## 三、粗细

- 竖画 104、横画 60（`han.V0`、`han.H0`），2026-10-20 定下，不改（见 DESIGN.md「已定的风格」）。
- 笔画多的字整体减细，按整字的轮廓条数（`len(shapes)`）分档：

  | 轮廓条数 | 手摆的字 | `lr()`、`tb()`、`bao()` 拼的字 |
  | --- | --- | --- |
  | 5 条以下 | 1.0（不减） | 0.92 |
  | 6 条 | 0.92 | 0.92 |
  | 7～9 条 | 0.9 | 0.9 |
  | 10 条以上 | 0.88 | 0.88 |

  拼出来的字部件压进了窄格，笔画挤，所以最少也减到 0.92（`lr()`、`tb()` 的默认值）。手摆的字用 `with weight(k):` 或 `_w(k, …)` 包起来。同一个字只用一档，不给单个部件另调粗细；`weight()` 不要嵌套，里层会直接盖掉外层，不是相乘。
- 部件放进小格子时，横竖的粗细不变，「有大小」的东西缩得少一点（`m.k`，格子缩到一半时约 0.66，不会放大）：点、钩、口字框的脚 × `m.k`；捺的最粗处、写明了的撇起笔粗 × `0.8 + 0.2 × m.k`；提 × `0.85 + 0.15 × m.k`。这些 `D_()`、`N_()`、`P_()`、`T_()` 已经处理，部件里一律用它们，不手算。

## 四、笔形

每种笔画都用 `han.py` 里现成的函数，参数先用默认值，确实不合适再调，调过的写进注释。

| 笔画 | 写法 | 默认值和取值 |
| --- | --- | --- |
| 横 | 左端微斜的入笔，右端圆润的喙 | 喙高 `min(48, 18 + 长 × 0.055)`、宽 `min(96, 34 + 长 × 0.1)`；短横、字里的次要横用 `beak=0.5～0.7` 压矮，0.3～0.4 只给很挤的地方 |
| 竖 | 起笔左高右低斜切加圆肩（`head`），收笔垂露（`dew`） | 悬针（`needle`）现在只用在 十、中、干、年、早，新加的字要用悬针，先写进这一格 |
| 折 | 横和竖画成一条轮廓，肩画在轮廓里 | 肩隆起 16 |
| 钩 | 竖钩、横折钩、竖折折钩的钩用默认长度 | 竖钩 `dx=−110, dy=80`，横折钩 `dx=−120, dy=86`；不再拉长到 150～180（2026-10-21 统一过）。小部件里的钩按部件大小收短（扌、也、月字旁） |
| 撇 | 粗起细收 | 起笔粗 `1.02 V`，收尖 10；起笔露在外面用 `cut`，藏进别的笔画用 `hid` |
| 捺 | 起笔藏进别的笔画，越写越粗，平出捺脚 | 最粗 `1.18 V`，起笔 30；捺脚比终点再往右伸出 `foot` × 最粗，默认 0.62（平捺 0.42～0.45，人 0.7，又、渡、度 0.75），画捺时终点要给脚留出这一截 |
| 点 | 尖头入笔，圆头收笔（对应西文的球形收笔） | 粗 `1.2 V` |
| 提 | 圆头起笔，往右上收尖 | 起笔粗 `1.08 V` |
| 口字框 | 左竖、横折、底横三条轮廓，底横两端藏进竖里 | 竖出底横的脚默认 44，小口 30～34；「四」留长脚；白 百 西 品 由 者 各 的框底和 日、古 对齐 |

- 部件压进窄框时捺脚会往右冲出字面框：给部件加收短捺的参数（如 `pu(na_end=…)`、`you_r`、`zou_di(na_end, shu_end)`），不去改捺本身的画法。
- 斜着往上写的横（七、代）用 `tilted()` 转，不另画一种横。

## 五、轮廓

这些由 `tools/check.py` 核对，细节见 DESIGN.md「检查」：

- 每一笔（连笔也算一笔）一条闭合轮廓，源码里按顺时针给节点（墨在走向的右边），输出时 `Shape.draw()` 统一成外轮廓逆时针。转角的肩、喙、圆头都画在轮廓里，不拼补丁。
- 节点放在曲线的极值点和转角，写明经过时的走向；弯度用张力调，默认 0.56。
- 不相连的笔画在笔画深处交叉；该藏进别的笔画的端点标 `hid`，有意做出的尖标 `tip`。
- 一笔不能整个落进另一条轮廓里（macOS 的系统渲染会把它当成字怀镂空）：框里的短横并进外框一起画，横之间挖字怀（月、用）。
- 不相连的两块墨之间至少留 34；两笔的边不擦边（夹角小于 15°）、不贴着走（相距不到 4）。

## 六、结构

- 左右、上下、半包围的字一律用 `lr()`、`tb()`、`bao()` 拼，部件间距由程序按 STRUCTURE.md 自动摆（左右 92、上下 76，阝 60、忄 76）；不手写右框、下框的位置来凑间距。
- 拼不了的字（独体字、品字形、框里套框）手摆，要过 `tools/structure.py` 的字面、重心检查。
- 笔画少的字撑开：长横画到 x 56–944，不缩在中间；窄字（目、自、月、日、口）按自己的比例收窄。
- 部件之间不能相碰，特意接笔的写法除外。

## 七、部件

- 一个部件只画一份。画新字前先搜有没有现成的（`grep -n "def 名字" *.py`），已有的直接用；形状不合适就给部件加参数，不另画一版。单字本身就是一个部件时（其、主、文、合、不……），单字直接返回 `部件(ID)`，不在两处各写一份坐标。
- 命名用拼音：左偏旁 `_left`（`ren_left`）、字头 `_top`、字底 `_di`、右边 `_r`；单字函数 `c_拼音`，同音字加义（`c_he_river`、`c_he_and`）。函数第一行注释写上它是哪个字、哪个部件。
- 部件函数的签名统一是 `f(m=ID, …)`，所有坐标都过 `m`（`H_`、`S_`、`P_`、`N_`、`D_` 这些映射过的笔画）。

## 八、西文

- 数字都在 `latin.py` 开头：x 高度 540、大写 720、升部 760、降部 −220；小写主干 100、细线 50，大写主干 108、细线 52；圆形字母上下过冲 12（大写 14）。
- 数字是齐线数字，高 700；粗笔、细笔和小写一样，收笔的球和 a、c 的一样。标点的点都是同一个圆点（半径 60），逗号、引号是圆点拖一条尖尾巴。
- 每个字母一条外轮廓加字怀，竖和拱、竖和碗相接处放角点，衬线用 `latin.py` 里现成的零件（`flag`、`head`、`foot`……），不单独画。
- 边距：小写、数字、标点 40，大写 50；需要调的在字形函数里返回额外边距，不改全局值。
- 字距按形状分组写在 `kern.py`，不逐对手填。
- 和汉字对应：西文的楔形衬线对应横画的喙，球形收笔对应点，主干 100 / 细线 50 对应竖 104 / 横 60。

## 九、一批字的流程

1. 按字频挑字，先挑现有部件能拼的。
2. 画字：先写部件，再拼字，按上面的粗细档位减细。
3. `python3 build.py --strict` 没有报错，最后一行是「系统渲染核对通过」。
4. `python3 tools/proof.py 输出.png 新字…` 看节点；打开小样页，用系统渲染放大到几百像素看一遍，再看正文字号。
5. `python3 tools/similarity.py` 通过，报出来的单字看过。
6. 更新字数和版本：README、README.en、小样页（字表、部件表、「现在的状态」）、`brand/cover.html`、`build.py` 的版本号，DESIGN.md 补上新文件和新笔画。
