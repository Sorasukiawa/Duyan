# 汉字结构规范

部件拼字时，位置和间距不再一个字一个字手调，而是按这里的规定统一摆。数字都在 [`layout.py`](../layout.py) 里，`python3 tools/structure.py` 逐字核对（`build.py` 出字体前也会跑一遍）。单位是 1/1000 em，汉字字身是 x 0–1000、y −120–880。

## 字面

- **字面框 (30, −100)–(975, 880)**：所有的墨，包括捺脚、撇尖、提的圆头，都要落在框里，排成一行时才不会碰到旁边的字。捺脚会比捺的终点再往右伸出 0.6～0.9 个笔宽，画捺时终点要留出这一截。
- 窄字（目、自、月、日、口）按自己的比例收窄，不硬撑满字面框。

## 字面饱满

- 笔画少的字要撑开，不能缩在中间：长横画到 x 56–944（宋体的长横几乎顶到字身边），「小」的竖钩从顶到底、两点张开放低，宝盖头的左点和横钩往两边撑，「口」拉高，「二」「三」的横拉开距离。
- 怎么量：把每个字的字面宽高和系统宋体同一个字比（只比外框数字，不用它的轮廓）。2026-10-20 撑开以后，最窄的一个字从宋体的 78% 提到 87%。
- 粗细和收笔不动（见 [DESIGN.md](DESIGN.md)「已定的风格」）。

## 左右结构：`lr(左偏旁, 右部件, 右框)`

- 左偏旁画在 x 40–340 之间（约占三成），右部件占其余。
- **部件间距统一为 92**：右框的左边沿不手写，程序量出两个部件真实轮廓之间最近的距离，把右框挪到正好留出 92。
- 偏旁靠右一侧是细弧或点的（阝 的耳朵、忄 的右点），按轮廓量出来的间距看上去偏松，所以分别收到 60、76（`LR_GAP_BY_LEFT`）。冫 也一样收到 76（「决」右边起头是一竖，收到 60），写在各字的 `lr(..., gap=…)` 里。
- 重心横坐标在 390–580 之间。宋体里「队」「忙」这种左重右轻的字，重心也只在 415 左右。
- 左偏旁太重时，可以用 `lsx` 让它横向收窄。

## 上下结构：`tb(上部件, 下部件, 下框)`

- 字头（艹、宀、人字头）约占上面三成，字底（心）约占下面三成。
- **部件间距统一为 76**：下框的上边沿按两部件之间的距离自动摆。
- 重心纵坐标在 330–480 之间。

## 半包围：`bao(辶, 里面的部件, 框)`

- 里面的部件和「辶」不是上下关系，位置手摆，和「辶」之间留 50–140。

## 部件不相撞

- 不同部件之间不能碰在一起，特意接笔的写法除外。
- 部件里再套部件（「化」里的「亻」）时，要用 `m.into(...)` 让内层跟着外层的框走。以前「花」下面的「化」，就是因为「亻」没跟着缩放，顶到了草字头上。

## 例外

量出来超标、但目测平衡的字列在 `layout.CENTER_EXCEPT` 里，每个都写明理由：

- 队：左边是一整条竖加耳刀，右边只有一撇一捺，按面积算的重心一定偏左（宋体约 415，这里约 370）。

## 这些数是怎么定的

- 间距 92、76 取自原来看着舒服的字（你、他、好、打、认、安、守……）的中位数。
- 重心范围参考了系统宋体（Songti SC）同一批字的实测值，只用来对照数字，不用它的轮廓。

## 还没定的

- **汉字字面偏大**：现在汉字字面高约 960，西文大写高 720，中英混排时汉字显得大。常见的中西文字体，汉字字面约占字身的九成。要不要整体收小，牵涉到中西文配比，属于设计取舍，先列在这里。
- **字面框的上沿还没真正检查**：`tools/structure.py` 和 `layout.py` 量字面时只光栅化了字身（y −120～880），框外的墨被裁掉，所以「墨不出字面框」只查得出左、右、下三边。2026-10-21 用轮廓实量：351 个汉字里 236 个的墨顶高过 880（中位 896，最高「美」954），竖排或行高设成 1 时上下会碰。和上一条一起定下字面大小后，再把检查改成按轮廓量。
